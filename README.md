## 🚀 Key Highlights & Overview

**Vidyalayam (વિદ્યાલયમ્)** is engineered to empower school principals, teachers, and administrative staff by digitizing every core operation—from state-board compliant marks calculation (Ekam Kasoti) to daily morning assemblies (Prarthana Sabha), official student certificates, ID cards, and automated WhatsApp parent messaging.

### 🌟 Core Capabilities at a Glance

* **📊 એકમ કસોટી (Periodic Assessment Test / PAT) Engine**
  * Built-in Gujarat Education Board / GCERT standard grade boundaries (A1, A2, B1, B2, C1, C2, D, E).
  * Automated roll-wise marks entry with instant total, percentage, rank, and subject pass/fail statistics.
  * Single-click printable PDF progress reports and Excel exports.

* **📝 સત્રાંત પરીક્ષા (Term Examination) Management**
  * Semester 1 & Semester 2 multi-subject examination consolidation.
  * Comprehensive cumulative progress cards (પ્રગતિ પત્રક) ready for distribution.

* **📢 શાળા દૈનિક પ્રવૃત્તિઓ (Morning Assembly / Prarthana Sabha)**
  * **દૈનિક સુવિચાર (Daily Thought):** Curated inspirational Gujarati and English quotes.
  * **જાણવા જેવું (Daily Facts):** General knowledge and scientific trivia.
  * **દૈનિક પ્રશ્નોત્તરી (Daily Quiz):** Daily curated questions to challenge students.
  * **અભિવ્યક્તિ (Expression):** Thematic speeches and cultural topics.
  * **સમાચાર (Headlines):** Daily educational and current news.
  * **🔊 Audio Narration (Text-to-Speech):** Integrated voice synthesizer with Gujarati/English voice selector.

* **💬 Parent Messaging & Instant WhatsApp Dispatcher**
  * One-touch WhatsApp message delivery with customized templates in Gujarati.
  * Instant sharing of exam results, circulars, fee reminders, and attendance notifications.

* **🪪 ID Cards & Official Certificates Generation**
  * **Student ID Cards:** Instant layout designer with QR/barcodes, photos, batch printing, and zip export.
  * **શાળા છોડ્યાનું પ્રમાણપત્ર (School Leaving Certificate - L.C.):** Strictly formatted official legal template with General Register (G.R.) verification.
  * **બોનાફાઈડ પ્રમાણપત્ર (Bonafide Certificate):** Instant certificate issuing with verification seals.
  * **ચાલચલગત પ્રમાણપત્ર (Character Certificate):** Professional templates.

* **🧑‍🎓 Student & Staff ERP**
  * Multi-standard support (ધોરણ ૧ થી ૧૨ / Standards 1 to 12) across all streams (General, Science, Arts).
  * General Register (G.R. No.) records, conflict resolution, roll number assignment.
  * Universal multi-criteria student search.
  * Bulk import and export via Microsoft Excel (`.xlsx`).
  * Student photo management with instant download and crop utility.

* **💻 Online Exam & AI Question Importer**
  * Timed online exam portal for students with live question countdown.
  * AI-powered question importer from text/PDFs into structured multiple-choice questions.
  * Live exam analytics, scorecards, and ranking.

* **🌐 Online Admission Portal**
  * Public admission form for prospective parents.
  * Admin review, verification, and one-click student enrollment.

* **🛡️ Enterprise Administration & Cloud Reliability**
  * Multi-school isolation with Role-Based Access Control (RBAC).
  * School storage manager, security auditor, and temporary password generator.
  * Seamless Firebase Firestore cloud synchronization for offline and multi-device access.

## 💻 Local Development Setup

To run the application locally on your computer:

### 1. Prerequisites
- **Node.js**: v20 or v22 (LTS recommended)
- **npm** or **bun**
- **Android Studio** (optional, for native Android builds)

### 2. Clone & Install
```bash
# Clone the repository
git clone https://github.com/anantahir7721-sudo/vidyalayam.git
cd vidyalayam

# Install dependencies
npm install --legacy-peer-deps
```

### 3. Run Development Server
```bash
# Start the full-stack Vite + Express development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
# Compile web assets and backend bundle
npm run build
```

### 5. Sync to Android (Capacitor)
```bash
# Sync web dist assets with the native Android project
npx cap sync android

# Open project in Android Studio
npx cap open android
```
