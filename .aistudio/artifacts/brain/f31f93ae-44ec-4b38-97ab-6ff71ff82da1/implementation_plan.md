# જાવક પત્ર & લેટરહેડ: પ્રતિ (To / મેળવનાર) ૩-સ્તરીય ફોર્મેટિંગ

## અમલીકરણ સારાંશ (Implementation Summary)

ગુજરાત સરકાર અને શિક્ષણ વિભાગના સત્તાવાર પત્રવ્યવહારના નિયમો અનુસાર **"પ્રતિ"** બ્લોકનું સંપૂર્ણ ૩ સ્તરીય વિભાજન કરવામાં આવ્યું છે:

```
પ્રતિ,
[હોદ્દેદારશ્રી]       -> દા.ત. જિલ્લા શિક્ષણાધિકારીશ્રી,
[કચેરીનું નામ]      -> દા.ત. જિલ્લા શિક્ષણાધિકારીશ્રીની કચેરી
[સરનામું / સ્થળ]     -> દા.ત. જિલ્લા સેવા સદન, ભુજ - કચ્છ.
```

### મુખ્ય સુધારાઓ:
1. **ડેટા મોડલ (`OutwardLetter`):**
   - `recipientDesignation`: હોદ્દેદારશ્રીનું પદ (દા.ત. `જિલ્લા શિક્ષણાધિકારીશ્રી,`)
   - `recipientOffice`: કચેરી / શાખાનું નામ (દા.ત. `જિલ્લા શિક્ષણાધિકારીશ્રીની કચેરી`)
   - `recipientAddress`: સરનામું / સ્થળ (દા.ત. `જિલ્લા સેવા સદન, ભુજ - કચ્છ.`)
   - પૂર્વવર્તી સુસંગતતા માટે `recipientName` ઓટોમેટિક કમ્પોઝિટ ફિલ્ડ તરીકે જળવાઈ રહે છે.

2. **પ્રેસેટ્સ (Quick Presets):**
   - DEO, DPEO, TPEO, BRC, CRC, મામલતદાર, પંચાયત અને વાલીશ્રી માટે સિંગલ ક્લિકથી ત્રણેય ફિલ્ડ્સ ઓટો-ફિલ થાય છે.

3. **નવા પત્રનું ફોર્મ UI:**
   - ૩ અલગ-અલગ સ્પષ્ટ ઇનપુટ બોક્સ:
     1. (૧) હોદ્દેદારશ્રી (Designation)
     2. (૨) કચેરીનું નામ (Office / Department)
     3. (૩) સરનામું / સ્થળ (Address / City)

4. **પ્રિન્ટ HTML & PDF આઉટપુટ:**
   - `buildLetterPrintHtml` માં `Anek Gujarati` ફોન્ટ સાથે પ્રતિ બ્લોકની દરેક લાઈન અલગ લીટી પર યોગ્ય માર્જિન અને ફોન્ટ વેટ સાથે સેટ કરવામાં આવી છે.

5. **પ્રિવ્યુ & રજિસ્ટર:**
   - A4 ફુલ સ્ક્રીન પ્રિવ્યુ, લાઈવ મિની કાર્ડ અને જાવક પત્ર રજિસ્ટર ટેબલમાં હોદ્દેદારશ્રી, કચેરી અને સરનામું ક્રમબદ્ધ પ્રદર્શિત થાય છે.
